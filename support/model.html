Assumptions

Decision outputs

Complete ledger per 100 dispatched orders

Return and RTO rates are mutually exclusive shares of dispatched orders. Production cost is consumed on retained units. Returned inventory remains recoverable stock, with separate net loss allowances. Every re-dispatch incurs a new handling and outbound event. The model excludes fixed factory overhead unless included in the chosen production cost or hurdle.

Price corridor and economic limits

k = 1 - r - t
Contribution / kept pack = P - C - K - [H + F + r × (R + Lr) + t × Lt] / k
Minimum sustainable price = C + K + [H + F + r × (R + Lr) + t × Lt] / k + factory hurdle
Programme price ceiling = 90% × matched benchmark
At fixed price, maximum return share = [(P-C-K-hurdle) × (1-t) - H - F - t × Lt] / [P-C-K-hurdle+R+Lr]

Demand, displacement and platform value

Kept packs Q = factories × SKUs × relevant views × view-to-dispatch rate × k
Attributable C2M kept value = Q × P
Displaced reseller value = Q × (1 - incremental unit share) × benchmark
Net kept-value change = Q × [P - (1 - incremental unit share) × benchmark]
The net kept-value change is an operating proxy, not official reported NMV or platform revenue. Meesho defines NMV as successfully delivered checkout value inclusive of taxes. Reconcile taxes, return adjustments and time windows with finance. A common tax rate would scale the comparable proxy by (1 + tax rate), but no unverified tax rate is assumed here. Platform approval also requires actual C2M contribution less displaced contribution and incremental programme costs.

Operating workload and scale

Four weeks per planning month. Manual comparison assumes 60 minutes per factory each week. This is a hypothesis, not measured current practice. Operating cost excludes engineering, initial verification travel, fraud losses and traffic opportunity cost. The unit operating hurdle is not a complete platform margin.

Category scoring and market frame

Scores are analyst hypotheses. Weights: cost advantage 35%, demand suitability 20%, lower return risk 20%, freight suitability 15%, ready-stock feasibility 10%. Hard gates override scores. The national formal reference universe is 14,079 textile + 9,759 apparel operating factories [14], not eligible C2M SAM. The Panipat planning proxy is 1,251 × 23% = 287.73, with 25-50% assumed qualification giving approximately 72-144. Register definitions need reconciliation before lead generation.
