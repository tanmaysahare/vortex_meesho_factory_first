Prototype walkthrough

The presentation QR opens the supplier side directly at the start of a fresh journey. It does not open this guide first.

Concept demonstration: use sample details only. Records, OTP, business verification, banking, orders, traffic, price benchmarks and payments are simulated. State is stored in this browser. This is not a live marketplace connection.

Start a fresh supplier journey

1. Fresh registration and factory application

  1. Open the prototype and select Start selling.
  2. Use the in-app Demo controls to fill sample details when needed. Follow registration, business, pickup, bank and store steps.
  3. Apply for Factory Direct and inspect the business-nature, production-stage and factory-evidence steps.
  4. Use the review preset below to see a populated review case, if you want to skip data entry.

2. Verify the price-to-action connection

Open populated launch scenario

  1. On the supplier side, open the sample cushion product from the catalogue.
  2. Change its price from ₹229 to ₹250 and save.
  3. The Factory Direct price tag pauses because the product no longer clears the required price advantage.
  4. Open the programme console using the in-app Demo controls, or open Action items in this same browser. Do not reload a preset between editing and checking.
  5. Find Sutradhar’s price exception. Assignment and activity show the operating response.

3. Verify the review-to-supplier connection

Open factory review scenario

  1. Inspect the factory application evidence.
  2. Request changes for the factory-photo requirement and confirm the decision.
  3. Open the supplier Factory Direct page in the same browser. The required change appears on the supplier side.

4. Explore other working flows

Inspect orders, stock editing, earnings, English/Hindi, programme settings and the activity log. Presets replace the active sample state, so use one journey at a time. The fresh-entry QR resets the local journey intentionally.

The strategy’s complete cost model uses an illustrative ₹225 / ₹250 scenario. The product’s ₹229 / ₹259 seed values and simplified profit display demonstrate interactions, not the complete economic validation. Use the interactive ledger for the proposal’s financial test.
